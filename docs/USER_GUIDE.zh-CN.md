# Pocket Transfer中文说明书

适用版本：0.3.0预览版。返回[项目首页](../README.md) · [下载安装包](https://github.com/hotpotly/PocketTransfer/releases/tag/v0.3.0)

## 一、安装

1. 在Release的Assets中下载`Pocket-Transfer-0.3.0-macOS-arm64.zip`。
2. 解压，将App拖入“应用程序”。不要直接从压缩包中运行。
3. 打开App。需要Apple芯片Mac、macOS 15或以上；当前下载包不适用于Intel Mac。
4. 本版未经过Apple Developer ID签名或公证。如果系统阻止启动，不要全局关闭门禁或删除系统安全配置。先确认来源和文件完整性；可审查源码后自行编译。[Apple的安全提示说明](https://support.apple.com/zh-cn/102445)介绍了相关风险与系统操作。

Release附有`SHA256SUMS.txt`。在下载目录运行`shasum -a 256 -c SHA256SUMS.txt`可检查ZIP是否与发布文件一致；哈希一致不等同于Apple安全审核。

## 二、首次无线连接

1. 开启Pocket，放在Mac附近，确保相机电量充足且无线连接可用。
2. 打开Pocket Transfer。没有搜索时，点击“搜索相机”。
3. 按系统提示允许蓝牙访问。相机出现后点击“连接”。
4. 首次配对时，在相机屏幕确认。若App要求输入相机Wi-Fi密码，在相机的无线连接设置中查看。
5. 等待素材列表出现。连接会临时把Mac的Wi-Fi切到相机热点，这期间原Wi-Fi不能提供互联网。
6. 在素材列表选择文件，点击导入按钮，并选定目标文件夹。
7. 等待完成后，点击“断开连接”。不要在导入过程中拔卡或关闭相机。

### 权限用途

| 权限 | 用途 |
|---|---|
| 蓝牙 | 发现相机、配对与建立连接 |
| 本地网络 | 读取相机素材和缩略图 |
| 定位 | macOS读取当前Wi-Fi名称所需，用于恢复原网络；不记录地理位置 |
| 通知 | 相机可用提醒与导入完成提醒 |
| 文件夹／可移动卷 | 保存素材，读取USB-C设备或读卡器 |

拒绝权限后可在系统设置中手动调整。系统权限提示应由你本人确认。

## 三、USB-C或读卡器导入

1. 使用支持数据传输的USB-C线连接相机。
2. 在相机上选择文件传输／存储模式，不是摄像头模式。
3. 在App的USB-C区域打开存储卷。没有显示时点“刷新”，或“选择设备”手动选择卷或DCIM目录。
4. 选择素材并导入。USB方式不需要切换Wi-Fi。
5. 完成后先“推出”存储，再拔线。手动选择的普通目录可能只显示“返回”。

仅充电线无法传输数据。某些相机连接模式不会挂载为存储卷，此时该USB导入方式不可用。读卡器识别成功不表示所有相机USB-C直连都经过测试。

## 四、文件夹与文件保护

- 默认保存到`~/Downloads/Pocket Transfer/`，可在设置中更改。
- 每批手动导入都会询问目标目录，记住上次位置；取消选择不会导入。
- 向正在进行的队列追加文件时，使用该批次已经选定的目录。
- 可按拍摄日期建立子文件夹。
- App保留相机原文件，不提供删除相机素材按钮。
- USB同名文件内容不同会报冲突；无线遇到未记录的同名目标文件也不会覆盖。遇到冲突可改用新的空文件夹。
- 无线下载支持部分文件续传，但重连或重试能否完成取决于相机响应。失败文件不要当作完整备份。
- 视频音轨保持原样；只有相机提供配套WAV时才一并导入，不会自动把视频转换为音频。

## 五、相机开机提醒与自动导入

1. 先在App中成功配对相机一次。
2. 在设置中开启“发现已配对相机时通知”，并允许macOS通知。可点“发送测试通知”验证权限。
3. 让App保持运行。关主窗口不退出，菜单栏相机图标可以重新打开。
4. 相机开机且蓝牙广播可见时，App会发出通知。点击通知后才连接并导入新增素材。
5. 使用上次选择的文件夹；目录不存在或不可写时，弹出选择框。
6. 通知触发的批次完成后会断开相机。普通手动导入是否完成后断开，由设置中的开关决定。

没有点击通知时，不会自动连接相机、切换Wi-Fi或导入素材。测试通知只打开App，不导入。

提醒检测的是已配对设备的蓝牙可见性，不是相机电源开关。连续在附近不会反复通知；超过90秒未见后再出现才重新提醒。睡眠、专注模式、蓝牙关闭和完全退出App都会影响提醒。本版没有安装开机启动项，重启Mac后需要打开一次App。

## 故障排查

### 找不到相机或连接慢

确认蓝牙权限、相机无线功能和距离。退出可能正在占用相机连接的其他App后重试。第一次配对必须在相机上确认。公开版没有承诺固定连接耗时。

### 传完后Wi-Fi显示已连接，但打不开网页

先在Pocket Transfer点“断开连接”，等待恢复结束。App将“Wi-Fi未恢复”和“Wi-Fi已恢复但联网检测未通过”分开显示。

后者的“重新检测”只检测互联网，不会再次断开Wi-Fi。检测使用系统路由、VPN和代理，不修改它们。单个检测网站不可达也可能导致提示，并不证明全部网站都不可达。

仍不能上网时，检查系统Wi-Fi是否为平时使用的网络，以及VPN是否重新连接。可自行进行一次VPN开关对照排查，但App不会代你关闭VPN。开启VPN时的检测已做本机验证；完整相机传输后的所有网络组合尚未验证。

### 没有收到通知

确认相机已配对、App未完全退出、系统通知允许、专注模式未抑制通知。连续开关相机可能尚未达到90秒重新提醒间隔。

### 无法导入到所选目录

检查磁盘是否在线、剩余空间与写入权限。外接盘断开后重新选目录。先导入少量素材核验；正式素材至少保留一份独立备份。

### 想反馈问题

在[本仓库Issues](https://github.com/hotpotly/PocketTransfer/issues)描述App版本、macOS版本、相机型号、连接方式和操作步骤。请先删除日志或截图中的文件名、完整路径、设备标识、网络名、密码等私人信息；不要直接公开整份日志。

## 七、数据存放与更新

- 素材：默认`~/Downloads/Pocket Transfer/`，或你指定的目录。
- 缩略图、导入记录、日志：`~/Library/Application Support/Pocket Transfer/`。
- 偏好与配对记录：本机UserDefaults，标识为`dev.ly.pockettransfer`。
- 相机密码：手动输入时按需存入系统钥匙串，不随安装包分发。

下载新版本后，先退出旧版，再替换App。导入目录和本机状态独立于App安装位置。不会自动删除旧素材。自动更新关闭，请只从本仓库Release取新版本。

## 八、已知限制

这是社区预览版，不是大疆官方软件。Pocket 3基于上游验证过的协议；Pocket 4 Pro在早期定制版中有无线导入实机记录。公开版的完整通知导入、Wi-Fi恢复和各型号USB直连仍需更多实机验证。不支持Sony相机，不包含实时拍摄控制或摄像头功能入口。
